# 三术合参 DesignSystem V6.1：东方精仪 · Oriental Precision

定稿日期：2026-11-11。冻结基线：`1ae6503994940414ab31afb4906cb7b32d291d82`。视觉总原则：**内容如册页，导航如玻璃，仪器如腕表**。

本次交付包括明确的设计参数、真实源码映射、可用 SwiftUI 基础组件、Web 可移植样式和实施指令。当前代码已把旧 `Ky` 配色、`kyCard()` 和 `KyPrimaryButton` 接到 V6；逐页重排、全系列海报和 PDF 分页仍按后续批次实施。不能把这份定稿等同于全 App 已完成改版、Web 已上线或真机性能已验收。

设计采用 Apple 已公开、当前 SDK 可用的能力，不预设 2027 年 API，不承诺获得设计奖。依据：[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Adopting Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)。玻璃承担导航与控制；盘面、正文和文档使用稳定的不透明底。

### 1.3 尺度、字体与控件

| 对象 | 最终参数 | 行为 |
| --- | --- | --- |

| 内容卡 | 18pt continuous；0.7pt 内描边 | 默认无阴影；增强对比时描边 1.4pt |

| 卡标题 | `.title3` serif semibold，标准 20pt | 小标题保持 8pt 下间距 |
| 正文 / 辅助 / 依据 | `.body` 17 / `.subheadline` 15 / `.footnote` 13pt | 语义字号随 Dynamic Type；正文行距 4pt，详解 5pt |

| 主按钮 | 最小高 52pt；圆角 14pt；内距 H16/V14pt | 允许多行增高；填充色/前景按主题配对 |

### 1.4 动效、玻璃和触感

| 交互 | 参数 | 降级/边界 |
| --- | --- | --- |
| 主按钮按压 | 0.985 倍；easeOut 180ms；透明度 0.92 | Reduce Motion 不缩放 |
| 胶囊选中 | spring response 0.28s / damping 0.88 | Reduce Motion 直接切换，不飞入 |
| 解释展开 | easeInOut 240ms | 不在滚动列表持续做几何测量动画 |
| 三方四正飞线 | 单次 easeOut 450ms，Canvas 绘制 | Reduce Motion 直接显示静态线；离屏停止动画 |
| 玻璃控制条 | iOS 26 原生 regular glass；17–25 regular Material | 降低透明度/增强对比时实色；不叠 glass on glass |
| 罗盘触感 | 用户主动拨盘跨主要 15° 刻度时轻反馈，至少间隔 125ms | 不把传感器流/噪声转成震动；尊重关闭设置 |
| 压盘准星 | 拖动只更新视图变换，结束时轻反馈 | 不改真实坐向、宫序、测量原始值 |

P1 仅主按钮使用新动效；旧 `KyMotion` 保持原样，P3 按视图逐项替换并删除不必要的循环，避免大范围改动行为。静态纸纹以后使用低对比预渲染纹理，不每帧生成噪声；列表无动态大阴影、实时高斯模糊或永久辉光。

120Hz 对应约 8.33ms 帧预算，是实机性能目标。Canvas、transform、opacity 并不保证全部操作由 GPU 完成。必须在目标设备使用 Instruments/Animation Hitches 测量滚动、宫位选择、旋盘与长图预览，再报告帧耗时与卡顿；低电量模式和系统调度由系统决定。

## 2. 核心页面重构定稿

完整逐组件规范、入口与失败态见 [SCREEN-SPEC.md](design-v6/SCREEN-SPEC.md)。以下是统一实施方向。

| 页面 | 结构/视觉 | 关键交互与必须保留的事实 |
| --- | --- | --- |
| 智能首页 | 品牌顶栏 → 命主中枢 → 今日天地 → 五主题阅读 → 四大旗舰 2×2 → 最近/全部工具 | 切人和建档不藏；无档案有真实门禁；全部工具零丢失 |
| 个人中心 | 当前命主名片；档案/报告/备份首组；回验/记录次组；显示/语言/规则末组 | 取消建档不写数据；删除后所有个人盘回空态；备份有失败与恢复反馈 |
| 八字细盘 | 四柱横向节奏、五行双编码；时间层胶囊；结论—依据—详解纵向阅读 | 点干支/十神/神煞进半高抽屉；古籍只展示真实原文和来源；缺来源明确说明 |
| 紫微十二宫 | 宫格实色；中央留白；选中宫 1.2pt 金线/色底/选中标；四化角标 | 使用现有三方四正关系；Canvas 飞线不遮字、不抢触控；提供宫位列表等价阅读 |
| 奇门九宫 | 九宫为主，时间/地点/流派固定摘要；天地人神层筛选；解释单独阅读 | 保留局数、门星神/三奇六仪原值与方位；不在 UI 补算吉凶 |
| 堪舆/罗盘/压盘 | 恒深精密仪器，36–44pt 读数；质量来源首屏可见；透明度/准星控件浮层 | 真北/磁北/校正状态清楚；拒权/低水平磁场/无效输入不能被装饰遮住 |
| 手相/面相与其他工具 | 采集 → 质量反馈 → 结果分层 → 依据/限制；统一卡片、字号与动作 | 沿用既有能力与权限；未实现识别能力不以新入口冒充上线 |
| 解释阅读器 | 先一屏可读摘要，再「本盘事实—规则—原文—白话—条件—回验」 | 默认解释专业词；详情可展开；不以增加字数制造无依据结论 |
| 报告/海报中心 | 样式预览、固定主题、生成状态、历史记录、打开/保存/分享 | 旧文件仍可识别；相册/写盘结果以真实回调为准 |

首页尺寸补充：命主卡建议最小 156pt，今日卡最小 104pt，五主题入口最小 64pt（可随字增高），旗舰卡建议最小 144pt；这些是下限，不锁高度。普通字号两列，大字号/窄屏改一列。现有 `TodayFortuneCard` 只有三条文字，没有可追溯的五个分数，因此本次五维区域定稿为「综合 / 事业 / 财富 / 关系 / 身心」五个阅读主题，不画虚构进度。

## 4. Web 的真实交付边界

当前仓库未发现可运行 Web 工程，也没有确认同产品 Web 仓库。因此本批交付 [kanyu-v6.css](../design/web/kanyu-v6.css) 与 [theme-adapter-v6.js](../design/web/theme-adapter-v6.js)，它们是可移植参考，不是已上线的 Web 改版。

CSS 使用同语义色与 20/15/16px 间距、18px 卡圆角、52px 主按钮、44px 最小触达；数字 `tabular-nums`。阅读区 18px/1.75，正文宽上限 38rem。窄屏单列，普通手机核心区两列；768px 起工作台两列；1200px 起 260px 导航＋主区＋320px 解释栏。检查 320/375/390/430/768/1024/1440px 与 200% 缩放。功能卡的布局必须允许字增大后换行。

在真实工程中，以其现有主题存储绑定 `data-kanyu-theme`，复用 host 的 light/dark/system，不增加第二套 localStorage；SSR 安全、系统变化可订阅/释放。`prefers-reduced-motion`、降低透明度/增强对比有降级；print 禁止玻璃。年份 `String(year)` 或 `Intl.NumberFormat(...,{useGrouping:false})`。不得杜撰 `app/static` 或 React/Vue 入口路径，更不能为了接皮肤修改 API 字段、命盘顺序、算法或后台数据。
