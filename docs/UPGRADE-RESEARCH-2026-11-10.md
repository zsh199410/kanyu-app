## 本轮已实现（测试结果以 PR 的 CI 为准）

- 七大主题的白话指南，每个主题包含四步阅读/操作顺序与术语解释。
- 为全部 37 个注册工具增加专项说明：准备资料、操作阅读顺序、如何理解结果与限制。使用原创说明，保留原工具入口。
- 解盘条目可就地展开相关术语；实际条目数替代写死的“30条”。个人标记不再显示为算法命中率。
- 专业 PDF 不再把每项结论截成第一句，保留完整结论、机制、建议和时间范围；完整版增加白话术语附录。
- 原生语义背景和正文色；首页核心功能提前；工具描述可换行；搜索支持多关键词、空白、全角/大小写和部分用途别名；恢复的非法分类索引不再越界。
- 照片双文件都保存成功才返回记录；失败清理半成品并提示；UUID 文件名防止一秒内连拍覆盖。
- 两处八字海报 ImageRenderer 改为 MainActor，清理姓名文件路径并显示写盘错误。
- 新增单元回归与五个核心 Tab、指南入口的 XCUITest；截图作为 xcresult 附件保留。

## 优先级与验收标准

### P0：可安装、不会丢数据

1. 每次改动必须经过单元测试、模拟器冒烟、设备 Release、IPA CRC 与 SHA256。
2. 补齐照片以外的视频轨迹、AR、RoomPlan、ZIP 的失败提示和故障注入。
3. 检查人物/案件损坏文件后继续保存是否覆盖原档；恢复前备份、预览差异、可回滚。
4. 处理剩余 ImageRenderer 与 Sendable 警告（例如 PalmModule），不要全局关闭检查。

### P1：界面与解释整体升级

1. 首页围绕“选人物 → 看盘 → 读解释 → 留记录/导出”，减少装饰、重复卡片与术语堆叠；保留清楚的专业入口。
2. 新手/专业阅读模式、字号与动态字体、搜索、收藏、阅读进度、主题内目录；实际截图验收浅/深色及最大辅助字号。
3. 八字、紫微、奇门统一“结论—本盘事实—规则—白话—适用范围—回验”；跨术相同意见不当作独立证据，分歧也要展示。
4. 同一人物/同一盘的批注与回验隔离。**2026-11-12 复核 main `e6de1b1`**：`Sources/InterpretModule.swift` 中 `VerifyStore` 已使用 `kanyu.verifyMarks.v2`，按 `ownerID + "|" + itemID` 保存标记；缺失人物上下文时不读写。旧版 `kanyu.verifyMarks.v1` 仅保留供备份／人工迁移，不会静默归属当前人物。因此原先“当前按标题全局共享”的描述已过时，Issue #10 已关闭。**仍待验证**：人物切换、同名条目、重启、删除重建、旧数据恢复及真机端到端回归；当前调用链以标题作为条目 ID，稳定性及盘面版本隔离需进一步审计。主观回验比例不代表算法准确率。
5. 报告归档从临时目录升级为可管理的持久档案；加入人物 ID、口径版本与导出设置；补目录跨页、超长正文和同名人物测试。

### P2：有证据的新能力

- 地图罗盘、离线地点收藏、复测记录差异、户型比例与变换持久化。
- 历法/流派对照实验、出生时间范围候选盘与差异说明；不凭猜测自动定生时。
- 时间轴事件笔记、预先登记判断、盲法回验、样本与误差说明。
- 奇门飞盘及更多时间尺度、紫微流日流时、更多尺法和罗盘层：每一项先提交方法说明与金标准测试再上架。
- 如增加联网 AI，必须展示数据去向、失败状态、引用的实际盘面事实和费用；不伪装成离线引擎事实。

## 本轮的现实限制

Linux 环境没有 Xcode/iOS Simulator，不能在本地截图原生 App；因此没有完成截图驱动的视觉审计，也没有宣称布局已验收。CI 的 UI 冒烟只证明被测导航和界面元素，不代表所有交互、动态字体或硬件流程通过。竞品资料用于形成需求，不保证已“超过所有竞品”。以实际版本、测试日志和可下载产物记录进度。

## 补充核查：真实数据去向与标签可信性

AskClient 的实际请求包含 question；选中人物时还包含姓名、生辰、性别、经度和时间校正选项。关于页和 README 原先“无上传”的表述与源码不符，本轮已纠正，并在发送按钮附近明确列出字段。不改变接口字段或声称已审计服务端留存策略。

AskResponse 原先在服务端未提供 confidence 时默认显示“高”，并编造“逐句校验通过”的说明。本轮改为“未标注”，拒绝/降级标志优先，未知标签不当作可信；新增缺失、未知和矛盾标签的回归测试。

额外验收依据：[Apple 可访问性](https://developer.apple.com/design/human-interface-guidelines/accessibility)、[系统颜色](https://developer.apple.com/design/human-interface-guidelines/color)、[NOAA WMM 误差与适用范围](https://www.ncei.noaa.gov/products/world-magnetic-model/accuracy-limitations-error-model)、[iztro 官方开源库](https://github.com/SylarLong/iztro)。后者仅作为后续对照候选，尚未引入或用它验证本项目。
