# iOS 海报内容优先级 · 重点速览版

本任务依据最新用户明确决定：海报不再保留“本盘完整结果”和“依据与建议”两个重复板块。App 内的解盘和 PDF 仍保留原有全文、原有依据与建议；**只精简分享用海报的展示**。

## 实际改动
1. `Sources/PosterHighlightSelection.swift`：按照标题从已有 InterpretEngine 真正的 conclusion 读取重点，原文开头摘录最多 88 个字符，不虚构、不调用另一套算命算法；出现省略号时明确是节选。
2. `Sources/PosterDynamicTemplateView.swift`：把原来“全部 30 项 + 详细机制/建议”的海报数据替换为结构化速览。命盘四柱、五行 5 项、大运邻近节点保留精确原值；重点围绕命局、喜忌、岁运、性格、事业、财运、婚恋、贵人，尊享加少数生活主题；传统颜色/方位仅在既有引擎有对应项时显示。
3. `Sources/PosterPagedExport.swift`：PNG 打印版移除每条“先看懂”“本盘完整原文”“来源/依据”重复字段，也不在图片上印 UUID 收据；后台 ZIP manifest 仍保留 ownerID、receipt 和每张 SHA256，方便追溯人物归属。四柱/五行/大运合并成紧凑信息条，正文优先显示重点标题与简短摘录。
4. `design/qa/PosterHighlightSelectionTests.swift`：新增四项来源保真与精简内容检查。原有 Tests/UITests/golden JSON 不动，使用专项 CI 临时运行。

## 内容取舍
- 保留：当前人物、四柱、五行比例、大运节点、主要人生主题、简短的传统民俗信息、页码与简短性质提示。
- 海报不显示：30 项详细长解读全文、逐条解释机制、古籍引文、所有来源详情、长段化解和完整建议清单。
- 这些内容仍可在 App 或完整版 PDF 中查看。海报每条仅取真实引擎结论的**一段节选**，不把节选当算法准确率或结果保证。
- 对空缺领域不编造内容，按真实存在的主题组装。

## 验收和风险
尚未跑当前精确 SHA 的 Xcode 原生编译、四矩阵截图、真机批量 ZIP 保存，未确认文字量测误差下的分页溢出。选取“结论首句”有可能并非最关键句；升级前需用真实样本审稿复核，必要时改为基于已结构化、可核对字段的人工作校准摘要。不得靠单次 CI 证明语义正确。
PR 保持 Draft，不合并或发布；不修改底层术数算法、已有 golden、Web/NAS、PR #25、G14、人物验收主线 #53。
