# iOS 海报自动分张与批量 ZIP 下载验收

数据源：PosterDynamicSnapshot。已支持八字与尊享入口；手相/紫微独立入口仍在其他 PR 中等待稳定人物 ID 接线。
流程：内容条目逐项原样读取 → 优先按中文标点拆段 → 每页按保守高度容量排版 → 1080×2100 PNG 独立渲染 → 解码确认尺寸 → 逐页 SHA256 清单 → ZIP 压缩 → iOS 原生 ShareLink 分享或存储。
每页有当前命主、风格、页号和来源。图片不使用带固定姓名或预测数字的设计 JPG。PDF 与 ZIP 目前尚未接入同一持久快照，不得宣称两者完全一致。
不允许因为内容很长而隐藏字段、删段落或把字号缩小到不可读。单条内容允许续段，全部续段串接必须与原文完全一致。
目前最多 120 张，超限会明确报错并建议使用 PDF，不静默截断。
新 XCTest 检查全字符、标点与换行保全、跨页顺序、同名不同 UUID、缺人物 ID 和超长报告拒绝。
未验证：本 head 原生编译和 XCTest、真实设备批量渲染稳定性、ZIP 逐页解码、iOS 分享系统、手相/紫微人员归属、PDF 同源、Apple Photos 保存；原有 Tests/golden/算法/Web/NAS/PR #25 都不修改。
