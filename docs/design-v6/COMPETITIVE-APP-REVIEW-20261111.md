## 当前交付优先级

1. 先保证已存在的 App 能编译、导出和使用：原有 109 单元＋1 UI smoke、三档实际 PDF、未签名设备包、CRC/SHA256 与提交一一对应。
2. 完成当前 11 图原生海报样例门禁和人工布局复核。首轮已实际发现无照片手相尺寸不符合竖版契约，失败已阻止发布；不能把其他十张的尺寸通过等同于视觉通过。
3. 完成用户可读性：主题解读展示现有完整结论/建议/依据；指南采用语义字号、分步卡片和展开术语；保留全部工具入口。长姓名、长说明、深色与辅助字号分别验收。
4. 继续核查人物切换、归档与恢复、同名人物报告归属、报告备份范围。当前历史按姓名分组和导出不在档案备份包内的限制已登记。
5. 新算法、年代扩展、通用笔记/提醒、真人咨询等分别定义输入、存储、异常与测试。当前阶段保持排盘算法、Tests/UITests 和金标准资源不变。

可强化的现有能力包括真实校正来源/测量收据、个人回验隔离、内容哈希、实际 PDF 与海报验证证据。以上只说明本项目的实现方向；竞品公开说明未提及某项，不代表竞品没有该项。

## 本次核对的源码

- `Sources/AllToolsView.swift`：37 个注册入口、36 个普通目标页和风水勘察专用 Tab；此为静态映射检查，不是 37 条端到端操作通过。
- `Sources/PeopleModule.swift`：人物关系、标签、搜索和分组；没有以此推定通用研究笔记已完成。
- `Sources/ClassicsModule.swift`、`QuizModule.swift`、`InterpretModule.swift`：古籍白话、题库与朗读的已有实现。
- `Sources/ZiweiModule.swift`：紫微专业盘及时间层。
- `Sources/V6ExportQA.swift`、`design/run_poster_render_qa.py`：独立 Debug 原生渲染门禁；不代表相册权限、导出抽屉和真机性能验收。
