# 三术合参 iOS｜解盘大白话与自然语音（独立 Draft）

## 范围
- 仅现有 iOS 解盘阅读视图和语音；不改八字、紫微、奇门、七政、堪舆等计算引擎和输出 JSON。
- 保持 30 维解盘原文、盘面事实、法则、来源字段、时间区间、用户回验标记原样；新增解释层，不把传统术数推断包装成客观事实。
- 与 PR #53 人物验收、PR #17 旧回验文案以及 Issue #55 古籍来源可信度修复严格分离；本 PR **不宣称修复**「五典原文」误判。

## 页面结构
1. **一句话看懂**：各主题使用独立编写的简体中文导语；对每条已有原文提取首句作为本盘简读，并与原始全文分层。摘要不修改引擎文字。
2. **完整解盘**：保留 EvidenceChainView、盘面和依据、岁运/现实提示、回验等原有功能。
3. **自然语音设置**：整组/逐条朗读共享系统普通话音色、语速与试听；默认优先设备已安装的 premium/enhanced voice，缺失时回退普通话默认声。音色 ID 和语速为设备本地偏好，不上传声纹/出生数据。
4. **传统解读边界**：解盘是传统文化解释，不保证职业、健康、财富或事件实际发生；来源校对另见 Issue #55。
