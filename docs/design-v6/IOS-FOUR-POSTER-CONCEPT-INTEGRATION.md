# 三术合参 iOS · 4 款海报视觉样张接入合同

## 用户定稿（2026-11-12）
1. 手相个人指南：青黛金线 + 掌纹导览 + 道家山水
2. 八字古风长卷：宋纸绘卷 + 四柱与大运 + 古风漫画
3. 紫微星曜图鉴：玄夜星图 + 十二宫位 + 道家观星
4. 尊享预测单：书式详批 + 朱砂印记，保留“尊享”入口

此决定更新旧的“仅一款”展现口径：**现为四种不同产品的视觉方案，而非相互覆盖的同一条八字命盘计算结果**。保留既有 PosterStyle 枚举和原生报告/历史文件兼容。

## 实施范围
- `ReportCenterView` 新增可达的“海报设计作品库”入口。
- `PosterConceptGalleryView` 展示四张图的本地资源，点击进入全图预览，可导航到手相、八字、紫微或既有尊享的实际原生导出。
- 图中的出生信息/命盘数值为生成式设计占位，画廊有明确提示；它们**不进入真正导出、存档、用户记录或复制为报告**。
- 未改动命理引擎、个人档案存储、Tests/UITests、golden JSON、旧文件名后缀和老报告解析。
- 四张 JPG 资产位于配套素材包 `Resources/PosterDesignPreviews/PosterConcept(Palm|Bazi|Ziwei|Premium).jpg`，发布前必须在 Xcode target 的 Copy Bundle Resources 中加入并实测加载。不随本次 GitHub 纯文本提交自动上传二进制。
