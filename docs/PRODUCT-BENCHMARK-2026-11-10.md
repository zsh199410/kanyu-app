## 产品目标

三术合参不以“预测更多”作为领先定义，而以以下五项同时成立作为质量标准：

1. **排得可复核**：每个关键结果有输入收据、算法口径、版本和金标准。
2. **合得有分工**：八字、紫微、奇门、堪舆的共识与分歧分别展示，不把相关意见伪装成独立证据。
3. **记得住上下文**：人物、课事、现场、报告、笔记和回验使用稳定 ID 关联，同名对象不串数据。
4. **坏了不丢数据**：所有写入原子化；备份有清单和校验；恢复可预览、可回滚、逐项报告。
5. **看得懂也能深挖**：新手看到结论与下一步，专业用户可展开盘面事实、规则、原文与差异。

## 分阶段路线

### P0：可靠性门禁（当前首批）

- 回验状态按人物/明确盘面来源隔离；旧版全局标记保留为待归属。
- ZIP 备份加入版本化 manifest、文件大小和 SHA-256；恢复前验证，损坏包停止写入。
- 为上述路径增加单元测试，并在 macOS CI 执行全部 XCTest、XCUITest、设备 Release 和 IPA 完整性检查。
- 下一批：恢复预览、恢复点与完整事务回滚；iCloud 与本地 ZIP 使用同一清单协议；处理 Swift 并发告警。

### P1：统一体验与海报系统

- 首页主流程收敛为“选人物/课事 → 三术合参 → 证据 → 记录/回验 → 报告/海报”。
- 所有主要按钮使用动词和结果命名，补空状态、失败原因、重试与 VoiceOver 文案。
- 建立统一设计令牌：青黛用于结构导航，朱砂只用于风险/强提醒，玉色用于完成，金色用于典籍/证据；状态不能只靠颜色。
- 海报采用可测试模板系统：人物 ID、生成时间、口径版本、隐私开关、二维码/水印开关、超长文本与大字号适配；导出后验证像素、文件和分享失败。
- 支持浅色、深色、动态字体、减少动态效果和高对比度；用真实 iPhone 截图逐页验收。

### P2：领先能力

- “合参证据图”：同一问题下各术结论、事实来源、相互支持/冲突和不确定性可视化。
- “事件时间轴”：先登记预测，再记录实际事件，避免事后修改；统计只描述样本，不宣称科学准确率。
- “出生时间候选盘”：展示不同时辰导致的差异，不自动猜定生时。
- “现场复测”：罗盘校准、磁场质量、测点、照片、户型变换与复测差异成套保存。
- “本地优先 AI 助手”：确定性排盘留在本机；联网前显示将发送字段；回答逐句引用实际盘面事实并支持离线降级。任何医疗、财务、法律高风险结论必须限制和提示。

## 每次发布的硬门禁

- `git diff --check` 无错误；新增行为必须有回归测试。
- XCTest、核心 XCUITest、设备 Release 全部通过；测试数量和失败数从日志读取，不沿用旧报告。
- IPA 解包、Bundle ID/版本、资源和 SHA-256 核对；未签名包不得称为可直接安装。
- 真机验证必须记录机型、iOS 版本、步骤、截图/视频和失败项；模拟器不能替代相机、罗盘、定位、AR、RoomPlan、iCloud 和分享链路。
- 报告严格区分：已完成、CI 已验证、真机待验、设计待审、失败、未开始。
