# 堪舆勘察（Kanyu Survey）

风水勘察数据采集 App：按《勘察作业标准-SOP》把一次勘察变成照着走的任务单——建案表单、罗盘定向、逐步拍照/录像，最后导出一个数据包 ZIP，发回给分析端即可排盘断宅。

## 功能（v1）

- **建案**：类型（阳宅/阴宅/庭院）、建成年/入住年/大装修年、常住人出生年——记录表字段一次填好。
- **罗盘定向**：磁北＋真北双读，iOS 按定位自动校正磁偏角；自动换算二十四山与八宫；多测点记录互校（大门朝外/朝内、阳台、房后）。
- **任务单**：按类型生成拍照/录像/罗盘任务，每项有站位说明。
- **照片自带罗盘**：每张照片生成一张烙印版（时间＋真北度数＋山名＋GPS 压在图下黑条），原图同时保留。
- **视频自带罗盘轨迹**：录像期间每 0.5 秒采样一次方位，导出 `*_headings.json`，与视频时间轴对齐——比烙一个数更准，分析时按秒对位。
- **导出数据包**：ZIP 内含全部媒体、`data.json`（结构化全量数据）、`勘察摘要.txt`（人读版）。

## 安装（未签名 IPA）

本仓库经 GitHub Actions（macOS）云端编译，产物为**未签名 IPA**，在 Releases 下载后：

1. 用你自己的开发者证书签名安装（全能签 / ESign / Feather 导入 IPA ＋证书即可）；
2. 首次打开需在「设置 → 通用 → VPN 与设备管理」里信任证书；
3. 使用时允许相机、麦克风、定位权限（罗盘真北靠定位校正）。

## 数据去向

所有数据只存在手机本地与导出的 ZIP 里，App 不联网、不上传。

## 本地构建

需要 Mac + Xcode：`brew install xcodegen && xcodegen generate`，打开 `Kanyu.xcodeproj` 运行。
